# Jan Seva Kendra - Web Portal

A WordPress-based web portal designed for a local Jan Seva Kendra (Common Service Centre). This platform provides citizens with easy access to digital services, government scheme information, downloadable application forms, and service appointment requests.

## 🚀 Features

* **Service Catalog:** Categorized listings of available services (e.g., PAN Card, Aadhaar updates, Voter ID, Income Certificate, Passport services).
* **Document Repository:** Downloadable PDF forms and guidelines for various government schemes.
* **Responsive Design:** Mobile-first architecture ensuring accessibility across all devices.
* **Custom Theme/Plugins:** Built with optimized custom WordPress architecture for fast loading and easy content management.
* **Contact & Inquiry:** Integrated forms for citizen queries and appointment scheduling.

## 🛠️ Tech Stack

* **CMS:** WordPress
* **Language:** PHP 8.x, JavaScript, HTML5, CSS3
* **Database:** MySQL / MariaDB
* **Development Environment:** Local environment (Docker / XAMPP / LocalWP) compatible
